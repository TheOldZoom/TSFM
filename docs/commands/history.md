# `history`

**Aliases:** `hist`

Sync and inspect your locally stored listening history

**Usage**
```
tsfm history <sync|stats> [--user <name>] [--all] [--pages <n>]
```

**Flags**

| Flag | Description |
| :-- | :-- |
| `--user <name>` | Last.fm username (defaults to your configured username) |
| `--all` | sync: fetch your entire history instead of the default 50 pages |
| `--pages <n>` | sync: fetch a specific number of pages |
