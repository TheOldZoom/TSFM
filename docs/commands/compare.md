# `compare`

**Aliases:** `cmp`, `vs`

Compare listening habits with another Last.fm user

**Usage**
```
tsfm compare <username> [--period <period>] [--limit <n>]
```

**Flags**

| Flag | Description |
| :-- | :-- |
| `--period <period>` | overall, 7day, 1month, 3month, 6month, or 12month (default: overall) |
| `--limit <n>` | Top items considered per category, 1-200 (default: 50) |
