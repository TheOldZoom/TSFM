# `top`

**Aliases:** `t`

Show top artists, tracks, or albums

**Usage**
```
tsfm top <artists|tracks|albums> [--period <period>] [--limit <n>] [--user <name>]
```

**Flags**

| Flag | Description |
| :-- | :-- |
| `--user <name>` | Last.fm username (defaults to your configured username) |
| `--limit <n>` | Number of results to show (default: 10) |
| `--period <period>` | overall, 7day, 1month, 3month, 6month, or 12month (default: overall) |
