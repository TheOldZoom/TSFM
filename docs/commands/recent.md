# `recent`

**Aliases:** `r`

Show recently played tracks

**Usage**
```
tsfm recent [--user <name>] [--limit <n>]
```

**Flags**

| Flag | Description |
| :-- | :-- |
| `--user <name>` | Last.fm username (defaults to your configured username) |
| `--limit <n>` | Number of tracks to show (default: 10) |
