# `stats`

**Aliases:** `s`

Show top artists, tracks, and albums

**Usage**
```
tsfm stats [--user <name>] [--period <period>] [--limit <n>]
```

**Flags**

| Flag | Description |
| :-- | :-- |
| `--user <name>` | Last.fm username (defaults to your configured username) |
| `--period <period>` | 7day, 1month, 12month, or overall (aliases: week, month, year, all) (default: 7day) |
| `--limit <n>` | Items per list, 1-50 (default: 10) |
